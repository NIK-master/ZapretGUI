# ⚡ Zapret for ADHD (v2.1)

**Zapret for ADHD** - это современный, высокопроизводительный графический интерфейс (GUI) для утилит обхода блокировок `zapret` (winws) и `tgwsproxy`. Программа создана для того, чтобы в один клик "починить" YouTube, Discord и Telegram, не заставляя пользователя разбираться в консольных командах и сложных конфигурациях.

Разработано на C# (WPF) с использованием современной архитектуры.

## ✨ Ключевые возможности

*   **Умное сканирование (Smart DPI Diagnostics):** Встроенный сканер на базе PowerShell автоматически перебирает стратегии обхода и подбирает идеальный профиль конкретно под вашего провайдера.
*   **Работа в фоне:** Программа умеет сворачиваться в системный трей (System Tray) и тихо работать в фоновом режиме, не занимая место на панели задач.
*   **Мониторинг сети:** Встроенные виджеты для отслеживания входящей/исходящей скорости и пинга до европейских серверов в реальном времени.
*   **Встроенное автообновление:** Программа автоматически проверяет наличие новых версий на GitHub как для самого интерфейса, так и для ядер (`zapret` и `tgwsproxy`), предлагая бесшовное обновление.
*   **Гибкие настройки:** Режим фокусировки (отключение анимаций), режим цветовой слепоты, аппаратное ускорение (GPU) и управление автозагрузкой Windows.

## 🚀 Установка и запуск

1. Перейдите в раздел [Releases](../../releases) и скачайте последний `.zip` архив.
2. Распакуйте архив в любую удобную папку.
3. Запустите `ZapretGUI.exe`.
4. При первом запуске откроется **Мастер настройки**, который поможет скачать необходимые компоненты (ядра обхода) и настроить программу.
5. Нажмите главную кнопку **"Починить интернет"**!

## 🛠 Архитектура проекта

В версии 2.0 проект перешел на модульную архитектуру:
*   **`Core/`** - Бизнес-логика, не зависящая от интерфейса (`NetworkMonitor`, `ZapretScanner`, `TrayIconManager`, `UpdateManager`).
*   **`Views/`** - Визуальное представление (XAML и Code-Behind), отвечающее только за отрисовку и реакцию на действия пользователя.
